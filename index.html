Features

Built around how you actually drive.

⛽

Accurate Mileage

True tank-to-tank calculation. Automatically computes km/L, cost-per-km, running averages, and detects anomalies.

🔧

Record Maintenance

Track oil changes, brake pads, and garage bills. Kilometer countdown to your next scheduled service.

🚨

Tyre Pressure Card

Store factory PSI for front and rear tyres per vehicle. Check at petrol pumps right from your home screen.

🚗

Multi-Vehicle

Cars, bikes, scooters, and commercial vehicles. Instant switcher chips on every screen — no back-button navigation.

📄

Document Alerts

Store expiry dates for Insurance, PUC, RC, and Road Tax. Dashboard banner warns you before renewals lapse.

💾

1-Tap Backup

Export your complete vehicle history as a JSON file to Google Drive, WhatsApp, or local storage anytime.

Install Guide

Three steps,
five minutes.

  1. 1

    Download the APK

    Click the button below to grab the latest DriveLedger.apk from GitHub Releases.

  2. 2

    Install on Android

    Open the file, tap Install. Android may ask to allow "unknown sources" — approve it for this once.

  3. 3

    Add your first vehicle

    The onboarding screen launches automatically. Add a nickname, fuel type, and registration number — you're in.

⚠️ When updating later:

Never uninstall before updating! Simply install the new APK over the existing app. Android replaces the code and keeps your entire database untouched.
